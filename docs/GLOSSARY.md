# PG Near Me — Glossary

- **PG** — Paying Guest accommodation (India-specific term for a room/bed rented in a shared house, typically with meals, common in student/working-professional housing).
- **Lead / contact-reveal** — a seeker leaves a name+phone before an owner's contact number is shown; the analytics/UX pattern that Phase B wires to a real `leads` table.
- **Trust score** — a computed quality score per listing (0–100), distinct from the raw star rating.
- **AEO** — Answer Engine Optimization: optimizing for voice assistants, featured snippets, and AI Overviews.
- **GEO** — Generative Engine Optimization: optimizing to be well-cited/summarized by LLM-based search (ChatGPT, Perplexity, etc.).
- **Phase A / B / C** — see [ROADMAP.md](ROADMAP.md): JSON-driven public site → real database + admin → data pipeline + AI.
